# DU-WHO

대구대학교 재학생 및 교직원을 위한 교직원 안내 애플리케이션.  
교직원 연락처 검색, AI 기반 업무 안내, 전화 수신 시 발신자 자동 식별 기능을 제공한다.

## 프로젝트 개요

교내 전화 수신 시 발신 번호만으로는 어느 부서·누구에게서 온 것인지 알기 어렵다.  
DU-WHO는 대구대학교 교직원 DB를 기반으로 다음 문제를 해결한다.

- 전화 수신 중 발신자의 소속·직위를 화면에 오버레이로 표시 (Android)
- 이름·부서·담당업무 기준 교직원 빠른 검색
- AI 챗봇을 통한 부서 업무 및 담당자 자연어 안내
- 신분(학생/교직원)에 따른 정보 노출 범위 차등 적용

## 주요 기능

### 인증
- 학번/사번 + 비밀번호 로그인
- **로그인 상태 유지**: 체크 시 세션 파일(`session.json`)에 역할 정보를 저장하고 다음 실행 시 자동 로그인
- 로그아웃 확인 다이얼로그 및 세션 파일 삭제

### 교직원 검색
- 2,246명 교직원 정보를 로컬 SQLite DB에서 조회 (오프라인 동작)
- 이름·부서·담당업무 키워드 검색 (검색 범위 전환 지원)
- 한글 초성 인덱스 사이드바로 섹션 빠른 이동
- `ListView.builder` 가상화로 대용량 리스트 성능 최적화
- 카드 탭 시 상세 정보 바텀시트 (위치, 전화, 이메일, 담당업무)
- 즐겨찾기 저장·해제 (SQLite 영구 저장)
- 전화 발신 / 이메일 전송 바로 실행

### 신분별 정보 차등 노출
| 항목 | 학생 | 교직원 |
|---|---|---|
| 이름·부서 | 표시 | 표시 |
| 직위(title) | 비표시 | 표시 |
| 휴대전화 | 비표시 | 표시 |
| 위치 | 건물명만 | 전체 표시 |

### AI 교직원 안내
- Groq API (Llama 3.3 70B) 기반 자연어 챗봇
- 질의 키워드로 교직원 DB를 사전 검색한 후 컨텍스트로 주입하여 정확도 향상
- 대화 히스토리 유지 (초기화 버튼 제공)
- 타임아웃·네트워크 오류 메시지 처리

### 전화 수신 식별 (Android 전용)
- 전화 수신 시 교내 번호 여부를 DB에서 조회
- 발신자 소속·직위 정보를 오버레이 알림으로 표시

### 자동 업데이트 감지 (Android 전용)
- 앱 시작 시 GitHub Releases API로 최신 버전 확인
- 현재 버전보다 높은 릴리즈 존재 시 업데이트 다이얼로그 표시
- 설정 화면에서 수동 업데이트 확인 가능

### 설정
- 라이트·다크·시스템 테마 전환 (파일 영구 저장)
- 앱 버전 표시 및 업데이트 확인

## 아키텍처 결정 사항

### 로컬 우선 설계
교직원 DB 전체(2,246명)를 앱 번들(`assets/staff_db.json`)에 포함하고 최초 실행 시 SQLite로 이식한다.  
네트워크 없이도 검색·즐겨찾기·전화 발신이 완전히 동작하며, DB 인덱스(`name`, `department`, `user_id`)로 쿼리 성능을 확보했다.

### 검색 화면 성능 최적화
초기 구현의 문제였던 `cacheExtent = 9,999,999` + 전체 위젯 사전 생성 방식을 다음과 같이 교체했다.
- **`ListView.builder`**: 화면에 보이는 항목만 빌드하는 가상화
- **사전 계산된 오프셋**: GlobalKey 측정 대신 항목 추정 높이(`44px` 헤더 / `100px` 카드`)로 누적 오프셋을 미리 계산
- **`ValueNotifier`**: 스크롤 이벤트마다 `setState` 대신 초성 인덱스바만 선택적으로 갱신

### 신분 기반 접근 제어
`AuthService.effectivePhone()` / `effectiveLocation()`으로 표시 로직을 한 곳에 집중했다.  
UI 레이어는 신분 판별 없이 이 메서드 반환값만 사용한다.

### Android 전용 기능 격리
MethodChannel 호출, 전화 권한 요청, 업데이트 감지는 모두 `Platform.isAndroid` 가드로 분리되어 iOS 빌드에 영향을 주지 않는다.

### 세션 영속화
`SharedPreferences` 대신 `getApplicationSupportDirectory()`의 `session.json` 파일을 사용한다.  
기존 테마 저장 방식과 일관성을 맞추기 위해 파일 기반으로 통일했다.
