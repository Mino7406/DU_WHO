# DU-WHO
교내 교직원 전화번호 자동 식별 서비스

## 프로젝트 개요
* 교내에서 행정실, 연구실, 교수 등 다양한 부서에서 전화가 오는 경우, 발신 번호만으로 어느 부서에서 누구에게 온 것인지 알기 어려운 문제가 있습니다.
* 이로 인해 학교에서 오는 전화를 받지 않는 학생이 있거나, 업무 전화를 받을 때 누군지 검색해야 하는 번거로움이 발생합니다.
* 일반적인 전화 식별 서비스는 대학 내부 번호에 대한 정보를 제공하지 못하며, 외부 사용자에 대한 교직원 개인정보 노출 우려가 있어 교내 구성원을 위한 독립된 서비스가 필요합니다.
* 교내 포털에서 제공하는 검색 API를 활용하여, 전화를 건 대상이 누군지 알려주는 프로그램을 개발함으로써 학생과 교직원의 업무상 편의와 효율을 증대시키는 것이 목표입니다.

## 기술 스택 및 개발 환경
* **개발 플랫폼**: iOS, Android
* **개발 수단**: Flutter (iOS, Android 대응)
* **데이터베이스**: SQLite
* **개발 도구**: Visual Studio Code, XCode
* **협업 및 형상 관리**: Git & GitHub

## 주요 기능
* **교직원 전화번호 데이터 수집 기능**: 대학 홈페이지에 공개된 교직원 주소록 및 부서 전화번호 정보를 주기적으로 크롤링하여 데이터베이스를 구축합니다. 교직원의 이름, 소속 부서, 직위, 전화번호 등의 정보를 수집하여 SQLite 데이터베이스에 저장합니다.
* **전화 수신 시 발신자 식별 기능**: 사용자의 휴대전화로 전화가 수신될 경우 감지된 발신 번호를 데이터베이스에서 조회해 해당 번호의 교직원 또는 부서 정보를 확인합니다. 조회된 정보를 바탕으로 발신자의 소속 부서 및 교직원 정보를 화면에 표시합니다.
* **사용자 로그인 및 권한 관리 기능**: 사용자는 애플리케이션 이용 시 로그인을 통해 자신의 신분(학생, 교직원 등)을 인증합니다. 사용자 신분에 따라 애플리케이션에서 제공되는 전화번호 정보의 노출 범위를 다르게 설정합니다.
* **신분 기반 정보 노출 차등 기능**: 학생 계정으로 로그인한 경우 교직원의 소속 부서 및 이름, 기관 정보만 표시합니다. 교직원 계정으로 로그인한 경우 교직원의 이름, 부서, 직위 등의 상세 정보를 함께 표시하며, 교내 전화가 아닌 휴대전화 발신에도 대응합니다. 이는 실제 대학 홈페이지에서 신분별로 제공되는 정보 수준이 다른 구조를 반영한 것입니다.
* **전화번호 검색 기능**: 교직원 이름 또는 부서를 기준으로 연락처 정보를 검색할 수 있는 기능을 제공합니다.
* **교직원 정보 데이터 업데이트 기능**: 신규 교직원 정보 및 변경된 전화번호 정보를 자동으로 반영할 수 있도록 합니다.

## 기대 효과
### 사용자 측면
* 학교에서 걸려오는 전화의 발신자를 사전에 확인할 수 있어 중요한 전화를 놓치거나 불필요한 전화를 받는 상황을 줄일 수 있습니다.
* 전화 수신 시 발신자의 소속 부서 또는 교직원 정보를 바로 확인할 수 있어 학교 행정 서비스 이용의 편의성이 향상됩니다.
* 교직원 연락처를 일일이 검색하거나 홈페이지를 확인할 필요 없이 애플리케이션을 통해 빠르게 정보를 확인할 수 있습니다.
* 학생과 교직원의 신분에 따라 제공되는 정보 범위를 다르게 설정함으로써 개인정보 보호와 정보 활용 간의 균형을 유지할 수 있습니다.

### 서비스 및 기술 측면
* 대학 홈페이지에 공개된 교직원 정보를 활용하여 전화번호 데이터베이스를 구축함으로써 대학 내부 연락처 정보를 체계적으로 관리할 수 있습니다.
* 웹 크롤링 기술을 통해 공개 데이터를 수집하고 이를 서비스 형태로 활용하는 데이터 기반 시스템을 구현할 수 있습니다.
* 전화번호 식별 기능과 사용자 권한 관리 기능을 결합하여 대학 환경에 특화된 전화 식별 서비스를 구현할 수 있습니다.
* 향후 캠퍼스 생활과 관련된 다양한 서비스로 확장 가능한 스마트 캠퍼스 플랫폼으로 발전할 수 있는 가능성을 가집니다.
